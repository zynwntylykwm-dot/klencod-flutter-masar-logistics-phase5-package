# تطبيق الأندرويد (APK) — المسار العالمي اللوجستي v1.0.0-phase2

## 1) الملف
| البند | القيمة |
|---|---|
| الملف | `masar-logistics-v1.0.0-phase2.apk` |
| الحجم | 590 ك.ب |
| معرّف التطبيق | `com.almasar.logistics` |
| الإصدار | `1.0.0-phase2` (versionCode 4) |
| أقل نسخة أندرويد | 7.0 (API 21) — الأفضل 9+ |
| الاستهداف | API 33 (أندرويد 13) |
| التوقيع | مفتاح ذاتي `android/build/masar-release.keystore` (كلمة المرور `masar2026`) |

## 2) التركيب
1. انقل ملف APK إلى الهاتف (كابل / واتساب / Google Drive…).
2. افتح الملف → اسمح بـ«تثبيت من مصادر غير معروفة» لتطبيق الملفات/المتصفح الذي تفتح منه.
3. بعد التثبيت سيظهر التطبيق باسم **المسار اللوجستي**.

> التوقيع ذاتي (self-signed) لأن Google Play يتطلب حساب مطوّر وتوقيع Play App Signing. التثبيت المباشر يعمل عاديًا على كل أجهزة أندرويد.

## 3) أول تشغيل — عنوان الخادم
تظهر نافذة تطلب **عنوان خادم النظام (Node)**:

```
http://192.168.1.10:8080        ← مثال: حاسوبك على نفس شبكة الواي فاي
https://api.example.com         ← أو نطاق مستضاف
```

- اضغط **«بدون خادم الآن»** إن أردت الواجهة فقط (تعمل الشاشات والبيانات المحلية، لكن المصادقة والمزادات والمحفظة تحتاج الخادم).
- لتغيير العنوان لاحقًا: زر **⚙** الصغير أعلى يسار الشاشة.

لتشغيل الخادم على حاسوبك:
```bash
node server/server.js          # يستمع على 0.0.0.0:8080 افتراضيًا
# اعرف عنوان الحاسوب المحلي:
#   ويندوز: ipconfig   |   لينكس/ماك: ip addr / ifconfig
```
ثم افتح منفذ 8080 في جدار الحماية إن لم يتصل الهاتف.

## 4) ما داخل التطبيق
- **الواجهة الكاملة للنظام مضمّنة داخل الـAPK** (نفس `app/index.html` + `js/api-client.js` + `js/phase1.js` + `js/auctions.js` + `js/app-config.js`) — تعمل بلا إنترنت للمحتوى المحلي.
- تُقدَّم الواجهة عبر **خادم محلي داخلي** (`127.0.0.1` على منفذ حر) لضمان عمل `fetch` و`localStorage` والجلسات بشكل صحيح — لا أغلفة `file://` التي تعطّل الطلبات في WebView الحديث.
- المزايدة والمصادقة والمحفظة والبث اللحظي (SSE) تتصل بخادمك عبر العنوان الذي تدخله، مع شهادة CORS من الخادم (`Access-Control-Allow-Origin: *`) و`Autorization: Bearer`.
- الروابط الخارجية (مواقع الشركاء، الخرائط) تُفتح في المتصفح، وزر الرجوع يتنقل داخل التطبيق.

## 5) القيود الصريحة (بلا تجميل)
| البند | الحالة |
|---|---|
| اختبار التركيب على جهاز/محاكي حقيقي | **لم يُنفَّذ هنا** (لا يوجد جهاز أو محاكي في بيئة البناء). تم التحقق من: صحة التوقيع، البيان، وجود `classes.dex`، ووجود كل ملفات الواجهة داخل `assets/www`. البناء نفسه بلا أخطاء. |
| عمل المزادات/الدخول | يحتاج خادم Node قابلًا للوصول من الهاتف — بدون ذلك الواجهة في وضعها المحلي فقط. |
| خادم مضمّن داخل التطبيق | غير موجود: Node لا يعمل داخل أندرويد في هذا البناء. الخيارات: استضافة الخادم على VPS/نطاق، أو تشغيله على حاسوبك على نفس الشبكة. |
| الدفع الحقيقي | غير موصول (كما في تقرير المرحلة 2). |
| الإشعارات الفورية (Push) | غير مفعّلة؛ البث اللحظي يعمل أثناء فتح التطبيق فقط (SSE). |
| Google Play | غير منشور؛ يتطلب حساب مطوّر + AAB + سياسة خصوصية. |
| موقع GPS | الأذونات مطلوبة للوظائف الخريطة داخل الواجهة، والتطبيق لا يجمع موقعك بنفسه. |

## 6) إعادة البناء من المصدر
```bash
bash android/build-apk.sh
```
يُنزّل أدوات أندرويد (aapt2/d8/apksigner + android.jar) مرة واحدة ثم ينتج APK جديدًا موقّعًا.
المصدر: `android/app/src/…` (MainActivity + AssetServer) و`android/app/AndroidManifest.xml` و`android/app/res/`، والواجهة تُنسخ آليًا من `app/`.

> إن غيّرت كلمة مرور المتجر لاحقًا فلا بد من إعادة التوقيع بنفس المفتاح لتحديث التطبيق على الأجهزة المثبّتة — احتفظ بـ`masar-release.keystore`.

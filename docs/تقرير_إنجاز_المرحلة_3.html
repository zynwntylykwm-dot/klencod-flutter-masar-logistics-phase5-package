ب) إدارة متكاملة داخل صفحة الإعدادات

يظهر في أعلى صفحة الإعدادات قسم «🛡️ الإدارة والإشعارات» يفتح لوحة إدارة كاملة بنفس هوية التصميم وستة تبويبات:

التبويبما يمكن فعله
الخادمحالة الخادم الحقيقية (إصدار، Node، ذاكرة، مدة التشغيل، عدد المستخدمين/الموظفين/العملاء/الزوار/الجلسات/الشحنات/المزادات/الحملات)، حالة قنوات الإشعار، تفعيل الإشعارات على الجهاز، إشعار تجريبي، تنزيل نسخة احتياطية.
المستخدمونبحث وفلاتر (عملاء/موظفون/الحالة)، تفعيل وإيقاف فوري، تغيير الرتبة، إعادة تعيين كلمة المرور (كلمة مؤقتة تُعرض مرة واحدة)، إنشاء مستخدم، حذف ناعم.
العملاءقائمة العملاء مع عدد الشحنات والرصيد والرتبة، رسالة مباشرة، إيقاف/تفعيل، إعادة تعيين كلمة المرور.
الزوارإحصاءات حقيقية (زوار، زيارات، المتصلون الآن، المحجوبون)، رسم بياني لسبعة أيام، أكثر الصفحات زيارة، توزيع الأجهزة والمنصّات، حجب زائر/إلغاء الحجب.
الإشعاراتمُنشئ حملة (عنوان/نص/الجمهور/القنوات)، إرسال فوري، آخر الحملات مع نتائج كل قناة، سجل قنوات الإرسال.
السجلسجل تدقيق لكل عملية إدارية: المنفّذ، الإجراء، الكيان، الوقت.
الصلاحيات على الخادم لا في الواجهة: المستخدم العادي يُرفض بـ403 على كل مسارات الإدارة (مُختبر)، مدير الفرع يدير لكن لا يحذف، والمدير العام وحده يحذف وينزّل النسخ الاحتياطية. ولا يمكن منح رتبة مساوية أو أعلى من رتبة المنفّذ.

أهم الحالات المُثبتة

  • تشفير Web Push مطابق للمعيار: نص عربي كامل أُرسل مشفّرًا ثم فُكّ بنفس خوارزمية RFC 8291 وعاد مطابقًا (186 بايت).
  • توقيع VAPID: JWT بخوارزمية ES256 وتوقيع 64 بايت ومطالبات صحيحة.
  • عزل الجمهور: حملة «الموظفون» لا تصل للعملاء، وحملة «العملاء» لا تصل للموظفين، وحملة لمستخدم واحد تصل له فقط.
  • الإيقاف الفوري: إيقاف حساب يمنع الدخول ويسحب جلساته ورموز الوصول القائمة (token_version).
  • إعادة تعيين كلمة المرور: كلمة مؤقتة تعمل مرة واحدة، والجلسات القديمة تُرفض فورًا.
  • الصلاحيات: مستخدم عادي ← 403 على كل مسارات الإدارة الخمسة + منع إرسال الحملات؛ مدير الفرع ← عرض 200 وحذف 403؛ منع ترقية الذات.
  • الزوار: زيارة متكررة تُحدّث نفس الزائر (بلا تكرار)، لا يُحفظ IP صريح (بصمة مجزّأة فقط)، الحجب يوقف التتبّع.
  • النسخ الاحتياطي: 17 مجموعة كاملة + حدث تدقيق.

3 الشفافية: ما هو حقيقي وما يحتاج شيئًا منك

البندالحالةالتوضيح
الخادم والتخزين والمصادقة والصلاحياتحقيقييعمل الآن، وقاعدة البيانات على القرص مع كتابة ذرّية ونسخ .bak
لوحة الإدارة والمستخدمون والعملاء والزوارحقيقيكل بياناتها من الخادم — لا أرقام ثابتة في الواجهة
الإشعارات داخل التطبيق وWeb Pushحقيقيمُختبر معماريًا؛ الإرسال الفعلي لجهاز يحتاج سماح المستخدم بالإشعارات
FCM / APNsيحتاج مفاتيحكالخادم يبني الطلب ويوقّعه بشكل صحيح، لكن الإرسال يتوقف حتى تضيف حسابك
Nginx/Caddy/Dockerلم يُشغَّل هناملفات النشر مكتوبة ومُراجعة، لكن بيئة البناء هنا لا تحتوي Docker — تُختبر عند أول تشغيل على سيرفرك
تطبيق iOSيحتاج Macالمشروع جاهز؛ البناء والتوقيع يتطلبان Xcode وحساب Apple
APKمبني · غير مُثبَّتلا يوجد جهاز/محاكي في بيئة البناء — أُبلغ بأي خطأ تشغيل لأصلحه
بوابة دفع / تتبع شركات الشحنغير موصوليحتاجان حسابات تجارية ومفاتيح API — لم يُقلَّد أي منهما

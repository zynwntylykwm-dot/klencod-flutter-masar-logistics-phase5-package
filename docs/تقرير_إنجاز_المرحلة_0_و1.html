٣المرحلة 1: ما بُني فعليًا (لا واجهات شكلية)

أ) خادم وقاعدة بيانات

  • خادم HTTP مبني على وحدات Node الأساسية فقط — يعمل بأمر واحد بلا npm install.
  • تخزين مركزي دائم في data/: كتابة ذرّية (ملف مؤقت ثم إعادة تسمية) + نسخة .bak + طابور كتابة متسلسل يمنع تصادم الطلبات.
  • يقدّم الواجهة الأصلية نفسها من app/ — نفس الملف بعد إصلاحات المرحلة 0.

د) اللحظية والإشعارات

  • قناة SSE من الخادم: حدث shipment_created وshipment_updated وnotification — مُختبرة فعليًا (وصل الحدث خلال إنشاء شحنة أثناء فتح القناة).
  • إشعار داخل التطبيق + إشعار نظام المتصفح عند السماح.
  • جدول إشعارات دائم لكل مستخدم (غير مقروء/مقروء).

هـ) المفضلة والتقييمات (خلفية جاهزة للواجهة)

  • مفضلة على الخادم: إضافة/حذف/قائمة مع منع التكرار — جاهزة لربطها ببطاقات المواقع والمزادات في المرحلة 3.
  • تقييمات: 1–5 + تعليق، منع تقييمين لنفس المستخدم، حساب المتوسط — جاهزة لواجهة النجوم.

و) التكامل مع الواجهة دون أي تغيير تصميمي

  • api-client.js: كل قراءة/كتابة تمرّ من نقطة واحدة، مع بديل محلي تلقائي.
  • phase1.js: اعتراض الدخول/التسجيل/كلمة المرور، مزامنة الشحنات كل 20 ثانية وعبر SSE، بطاقة بيانات حية على الرئيسية، ومؤشر حالة صغير أسفل الشاشة.
  • لم تُحذف أي صفحة، ولم يُستبدل أي زر بواجهة شكلية؛ والوضع المحلي يعمل كما كان إن توقف الخادم.
